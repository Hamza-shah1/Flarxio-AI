Frequently Asked Questions

Everything you need to know about our free online file compressor.

Is this file compression tool completely free?

Yes — Flarixo AI's file compression tool is 100% free with no sign-up or credit card required. Just upload and compress.

What file types can I compress?

You can compress images (JPEG, PNG, WebP, GIF), PDF documents, videos (MP4, WebM), and many other common file formats in one place.

Will compression reduce my image or video quality?

Flarixo AI supports both lossless and lossy compression. Use the slider to set the level: at 0.7–1.0 quality is visually lossless for most files; lower values give smaller sizes with some quality trade-off.

What is the maximum file size I can compress?

You can upload files totalling up to 100 MB per batch. Individual files can be compressed, or batch-compress an entire folder at once.

Are my uploaded files stored on your servers?

No. Files are processed securely in memory and immediately discarded after compression. We never store, share, or access your files.

Can I set a specific target file size?

Yes — when compressing a single file, you can specify an exact target size in kilobytes (KB) and the compressor will optimize to hit that target.
